## Analiza przeprowadzona

### Struktura projektu
- `backend/` – Django 4.2 (Python 3.12) z aplikacjami: core, users, activities, events, clubs, rewards
- `admin/` – React 19 Dashboard (3 warianty: GLOBAL_ADMIN, LOCAL_ADMIN, MODERATOR)
- `mobile/` – React Native 0.76 (tracking offline-first)
- `web/` – React 19 (frontend marketingowy)
- `telemetry/` – FastAPI (async telemetry ingress, TimescaleDB)
- `infrastructure/` – Traccar, BRouter, observability, symulatory

### Stack technologiczny
**Backend:** Django 4.2, DRF, PostgreSQL + PostGIS + TimescaleDB, Redis, Celery, FastAPI
**Frontend:** React 19 + TypeScript, MapLibre GL, Vite
**Mobile:** React Native 0.76, background-geolocation
**Infra:** Docker Compose, Nginx, Sentry, Stripe, Matrix E2EE
**Python libs:** scikit-learn (IsolationForest), numpy/scipy, stripe, celery

### Architektura
- **Monolit Django** – logika biznesowa, CRUD, płatności
- **Mikrousługa FastAPI** – wysoka przepustowość telemetrii GPS → TimescaleDB
- **Multi-tenant** (tenant_id) + RLS + Citus sharding
- **Async pipeline Celery**: fast gate → ML anomaly → V-max → BRouter → pluginy

### API
Django DRF endpoints: auth (JWT), activities (CRUD, leaderboard Redis ZSET), privacy zones, events, clubs, rewards, health, Matrix E2EE verification, OGC Moving Features.
FastAPI: `/telemetry/ingest` (single/batch), `/live` (WebSocket), history.

### Database
- **PostgreSQL + PostGIS** – User, TenantProfile, Activity (LineString), PrivacyZone (Point), Event (Polygon), Participation, Achievement
- **TimescaleDB** – gps_points hypertable (time, device_id, user_id, lat, lon, speed, accuracy, activity_id)
- Douglas-Peucker simplificační tolerance 0.00001 (≈60% redukce)

### Key Features
1. **3-warstwowy Anti-Cheat** – kinematic gate, IsolationForest, V-max thresholds, BRouter topological validation
2. **Real-time leaderboards** – Redis Sorted Sets (O(log n) updates, sub-5ms reads)
3. **Kalman filtering, Viterbi HMM map matching**
4. **Privacy Zones** – dynamic masking, density boost
5. **Offline-first mobile tracking** – background location, batch sync
6. **Stripe payments, vouchers, points ledger**
7. **Moderator Command Center** – split-screen flagged list + map
8. **User Simulator** – warp/teleport testing of anti-cheat

### Observability
Sentry (GPS-stripping beforeSend), structured logging, health endpoints, Celery Beat (ML retrain, MV refresh), Prometheus/Grafana (ops)

### ADR & Patterns
- ADR 0001: Django over FastAPI/Node (batteries-included)
- ADR 0002: JWT stateless
- ADR 0003: Celery async
- ADR 0004: PostGIS geospatial
- ADR 0005: Redis Sorted Sets leaderboards
- Patterns: Pipeline, Strategy, Observer/Pub-Sub, Repository, Factory, Singleton, Command, Adapter
