## Mobile: Game Vibe Specification (SSOT)

### Filozofia
Aplikacja mobilna **nie jest narzędziem fitness** — to **gra w świecie rzeczywistym**. Każdy ekran, animacja i dźwięk ma komunikować: "jesteś w grze, twoje statystyki to twój ekwipunek, trasa to twoja misja".

### TrackingScreen — mapa jako arena gry

**Zasada główna**: Mapa to 90% ekranu. HUD to nakładka która **znika** po 3 sekundach bez interakcji. Pojawia się na tap.

| Stan | Co widać |
|---|---|
| **Idle** (przed startem) | Mapa 100% szerokości, jeden przycisk START MISSION (HD2DButton, dolna część ekranu). Minimal info: czas, temperatura, poziom baterii jako małe pikselowe ikony w rogach. |
| **Active** (tracking) | Mapa + cienka warstwa HUD: dystans + pace w lewym dolnym rogu (Metal Slug HUD box). Auto-hide po 3s. Tap przywraca HUD na 5s. |
| **Milestone** | PopUpDialog wjeżdza z dołu: postać + typewriter text ("5KM CRUSHED, SOLDIER!"). HUD znika w trakcie dialogu. |
| **Pause** | Mapa lekko przyciemniona (Octopath vignette), przycisk RESUME + ABORT. Statystyki sesji jako overlay. |

**Animacje**:
- Spring entry dla HUD (damping 14, stiffness 100)
- Floating idle na ikonach (AthleteSprite pulsuje ±4px)
- Distance counter: cyfry przeskakują z efektem "odliczania" (jak score w grze)
- Milestone: screen shake (haptics) + flash złotego koloru (Octopath bloom)
- Map zoom: płynne przejście między poziomami zoom (MapLibre `flyTo` z duration 2000ms)

**Stylistyka**:
- Mapa: MapLibre + styl `positron` (jasny) lub `dark-matter` (ciemny) zależnie od theme
- Ramka mapy: Metal Slug industrial border — 2px czarny + 1px złoty wewnętrzny
- HUD box: `RetroCard` z opacity 0.9, pozycjonowany absolute lewy dolny róg
- Wskaźniki: chunky pixel font (Press Start 2P), kolory Octopath (gold #D4A373, forest #7BA05B)
- Vignette: ciemny gradient na krawędziach mapy (Octopath tilt-shift efekt)

### Pozostałe ekrany — game vibe

| Ekran | Game vibe |
|---|---|
| **Leaderboard** | Podium jak w trybie rankingowym Metal Slug — złote/srebrne/brązowe sprite'y zamiast cyfr. "My Rank" jako floating HUD na dole — zawsze widoczny. |
| **Profile** | "Character sheet" — jak w RPG. Avatar jako pixel sprite, statystyki jako "attributes" (STR = distance, SPD = pace, VIT = consistency). QR code jako "identity token". |
| **Rewards** | "Item shop" — karty voucherów jak przedmioty w sklepie RPG. Ikona przedmiotu, nazwa, cena w XP. Przycisk REDEEM jak "BUY" w grze. |
| **Activities** | "Quest log" — lista ukończonych misji. Każda aktywność to wpis w dzienniku: data, typ, dystans, verification score jako "grade" (S/A/B/C/D). |
| **Onboarding** | "Character creation" — 5 kroków jak tworzenie postaci w RPG. Avatar wybiera klasę (Runner/Cyclist), wybiera ekwipunek (permissions), dostaje "quest" (pierwsza misja). |

## Release Candidate Phases (v0.2)

### Phase 1: "Real Data" (4-6 hours) 🔴
**The platform looks dead without this.**

- Backend: Admin stats endpoint (`/api/activities/admin/stats/`) — users, activities, verification rate per tenant
- Backend: Seed 50+ demo activities with realistic GPS data, varying verification scores
- Admin: Dashboard with real data, per-tenant breakdown
- Admin: ModeratorWorklist with real anomaly data (not "0 PENDING TICKETS")

### Phase 2: "Flows That Work" (6-8 hours) 🟡

- Admin: User create/delete form with role + tenant selection
- Admin: Fix WhiteLabelEngine (tenantId prop, deploy button, success feedback)
- Admin: Fix "Send Invitation Token" flow
- Mobile: POI markers on MapLibre map with tap-to-view voucher info
- Mobile: Real leaderboard data from DB endpoint
- Mobile: RewardsScreen — real balance + pool data, fix redeem flow

### Phase 3: "Game Vibe — Visual Foundation" (5-6 hours) 🎨

- Generate 11 critical MISSING pixel-art assets (hud icons, nav icons, sprites)
- TrackingScreen: map-first redesign with auto-hide HUD
- TrackingScreen: Metal Slug industrial border, Octopath vignette, spring animations
- Mobile: Empty states — AthleteSprite + typewriter text on all screens
- Mobile: Loading states — pulsating sprite instead of Spinner
- Mobile: Tab bar with generated pixel-art nav icons (replace lucide-react-native icons)
- Beta feedback form in admin panel (BetaFeedback model + view)

### Phase 4: "Strava Integration" (5-6 hours) 🏃

- Strava OAuth: backend endpoints (auth URL, callback, token storage)
- Strava Sync: import activities from Strava API → SPORT Activity
- Mobile: real Connect button → WebView OAuth → status display
- Manual sync button + auto-sync on first connect
- Error handling: expired token re-auth flow

### Phase 5: "Garmin Integration" (4-5 hours) ⌚

- Garmin OAuth: same pattern as Strava
- Garmin Sync: import activities
- Mobile: Connect button next to Strava

### Phase 6: "Infrastructure for Scale" (8-10 hours) ⚙️

- Celery workers on Railway (async anti-cheat layer 3-4)
- FastAPI telemetry deploy on Railway (live GPS WebSocket)
- Email/SMTP: SendGrid integration, password reset, user invitations
- BRouter server deploy + integration with Celery tasks

### Phase 7: "Polish & Stability" (5-6 hours) 🟢

- Global error handling: Mantine notifications (admin), Alert.alert (mobile)
- Stub cleanup: non-functional buttons → "Coming soon" tooltip
- React Native Bridgeless: enable `newArchEnabled`, verify library compatibility
- Citus sharding: cluster setup (3 nodes), distributed tables, shard rebalancing
- Performance: API response time <200ms P95, mobile 60 FPS on tracking screen
- Beta tester guide: step-by-step walkthrough, feedback form, known issues
