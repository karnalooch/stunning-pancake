# SPORT - Open Source Sports Platform

A modern, scalable B2B/B2C sports platform designed for competition, gamification, and precision telemetry.

## Documentation
Full project documentation can be found in the `docs/` directory:

- **[Project Constitution](./docs/constitution.md)** - Mission, identity, and visual manifesto.
- **[Backend Architecture](./docs/backend_architecture.md)** - Traccar, BRouter, Redis, PostGIS.
- **[Mobile Architecture](./docs/mobile_architecture.md)** - Flutter, Offline-first, MapLibre.
- **[AI Toolkit Standards](./docs/ai_toolkit_constitution.md)** - AI Quality and Safety rules (Safety Constitution).
- **[Python + TypeScript Strategy](./docs/python_typescript_strategy.md)** - "Power Couple" division of responsibilities.

## Tech Stack
- **Backend**: Python (Django/FastAPI) + PostgreSQL/PostGIS
- **Mobile**: Flutter
- **Infrastructure**: Docker
- **Telemetry**: Traccar (Apache 2.0)
- **Routing**: BRouter (MIT)
- **Communication**: Matrix (Apache 2.0)

## i18n Strategy
The application is designed to be **multi-language**, with **Polish** as the default locale for end-users.
