## Tenant onboarding steps

1. Fill `[...]` placeholders in rules and email.
2. Adjust schedule to `[START_DATE]` / `[END_DATE]`.
3. Send poster brief to designer — final PDF outside repo.
4. Publish rules and FAQ (city site / intranet / app link).
5. Attach [DPIA](../compliance/DPIA_TEMPLATE.md) and [subprocessors](../compliance/SUBPROCESSORS_TEMPLATE.md) before registration opens.
6. Anti-cheat policy link: `{admin-domain}/#/trust/anti-cheat`.
