## Onboarding tenanta (kroki)

1. Uzupełnij placeholdery `[...]` w regulaminie i mailu.
2. Dostosuj harmonogram do dat `[DATA_START]` / `[DATA_KONIEC]`.
3. Przekaż brief plakatu do grafika — finalny PDF poza repo.
4. Opublikuj regulamin i FAQ (strona miasta / intranet / link w app).
5. Dołącz [DPIA](../compliance/DPIA_TEMPLATE.md) i [podprocesorów](../compliance/SUBPROCESSORS_TEMPLATE.md) przed rejestracją.
6. Link do polityki anti-cheat: `{admin-domain}/#/trust/anti-cheat`.
