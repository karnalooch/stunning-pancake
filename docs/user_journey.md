# USER JOURNEY MAP: "SPORT" Platform
> Strategic Path to Habit Formation and Conversion

## Phase 1: Discovery and Onboarding (AIDA - Awareness to Action)
*Goal: 3-minute Time-to-Value (TTV)*

- **Landing Experience**: Focus on emotion ("Feel the freedom") rather than technical specs.
- **Social Sign-In**: One-tap registration via Apple ID (mandatory) and Google.
- **Progressive Disclosure**: Request biometric data only when needed for first analysis, not at account creation.
- **Contextual Permissions**: Trigger GPS and HealthKit prompts only at the moment of first activity start.
- **Passwordless**: Enable **Passkeys** (FIDO2) for frictionless returning sessions.

---

## Phase 2: The First Training (The Aha! Moment)
*Goal: Success in the first activity*

- **Start Screen**: Clear, high-contrast UI with a single primary action button.
- **Live Tracking**: Mapbox 3D terrain visualization with real-time pace and elevation.
- **Live Activities (iOS 18)**: Progress visualization on the lock screen without unlocking.
- **Immediate Feedback**: Automatic track saving, instant calorie calculation, and point awarding.
- **Celebration**: Reanimated 3 confetti and "First Step" badge to trigger dopamine loops.

---

## Phase 3: Analysis and Retention (Habit Building)
*Goal: Turning data into motivation*

- **Dashboard**: Beautiful charts (Tremor/Recharts) showing 12-week trends and ACWR (Injury Risk).
- **Engagement Loops**: OneSignal push notifications triggered by social segments ("Friends just finished 5km, join them?").
- **Social Proof**: One-click generation of "Activity Cards" for Instagram/TikTok with map overlays.
- **Community**: Automated entry into municipal/clan leaderboards.

---

## Phase 4: Monetization and Loyalty (Conversion)
*Goal: Transition to Premium via RevenueCat*

- **Dynamic Paywalls**: Personalized offers based on user behavior (e.g., "Weekend Runner" plan).
- **Entitlement Sync**: Seamless premium access across Web (Admin) and Mobile (Android/iOS).
- **Advocacy**: Referral program – 1 month Premium for each successful invite.
- **Sponsor Perks**: Redemption of earned points for real-world brand vouchers in the Marketplace.
