This document mirrors the Polish canonical pre-pilot assessment.

4VELO has not passed the current pilot release gate. Before a pilot involving real
users, the project must finalize the responsible legal entity, controller/processor
roles, lawful bases, subprocessors, retention, user-facing notices and safeguards for
automated anti-cheat outcomes that can materially affect a participant.

The platform design includes precise location data, activity telemetry, optional
heart-rate data, anomaly scoring and tenant campaigns. These features require a
documented data-protection impact assessment before production use.

The current assessment is **NO-GO** until the unresolved items listed in the Polish
canonical document are closed.
